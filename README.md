# mc-rkn-bypass

This is a modded version of **zapret**, originally created by [@bol-van](https://github.com/bol-van/zapret) and [@Flowseal](https://github.com/Flowseal/zapret-discord-youtube). It bypasses DPI blocking and includes the specialized **mc-rkn-bypass** strategy, which allows connecting to European Minecraft servers.

Это модифицированная версия **zapret**, изначально созданная [@bol-van](https://github.com/bol-van/zapret) и [@Flowseal](https://github.com/Flowseal/zapret-discord-youtube). Она обходит DPI-блокировки и включает специализированную стратегию **MC_EU**, которая позволяет подключаться к европейским серверам Minecraft.

> ⚠️ **IMPORTANT / ВАЖНО**
> 
> **EN:** To use the **mc-rkn-bypass** strategy, you must first download the official release from the [zapret](https://github.com/Flowseal/zapret-discord-youtube) repository by Flowseal.
> 
> **RU:** Чтобы использовать стратегию **mc-rkn-bypass**, вам необходимо сначала скачать официальный релиз из репозитория [zapret](https://github.com/Flowseal/zapret-discord-youtube ) от Flowseal.
>
> ## 🎮 Installation & Usage / Установка и использование

### 🔹 MC_EU.bat Strategy / Стратегия MC_EU.bat

**EN:** To use the **mc-rkn-bypass** strategy, simply download it and place it directly into your main **zapret** folder. To run it, open the file and press **Enter**.  
 
**RU:** Чтобы использовать стратегию **mc-rkn-bypass**, просто скачайте её и положите в главную папку **zapret**. Для запуска откройте этот файл и нажмите **Enter**.

> ⚠️ **ATTENTION / ВНИМАНИЕ**
> 
> **EN:** It is not recommended to keep this strategy enabled all the time. Many websites and services (like YouTube or Discord) that usually work with zapret might stop working properly due to the modified routing. Disable it when you are done playing.
> 
> **RU:** Не рекомендуется держать эту стратегию постоянно включенной. Многие сервисы (например, YouTube или Discord), которые обычно работают через zapret, могут перестать работать из-за измененных настроек. Отключайте её после завершения игры.
